# Platform review: Harbourgate

Product names as the course brief lists them. Vendors rename products often, so check each name on the vendor's own page before the board meets.

| Layer             | Contract                                                                                     | Check                         | AWS Bedrock AgentCore                   | Google Gemini Enterprise Agent Platform | Microsoft Foundry                     | Gap                                                                            |
| ----------------- | -------------------------------------------------------------------------------------------- | ----------------------------- | --------------------------------------- | --------------------------------------- | ------------------------------------- | ------------------------------------------------------------------------------ |
| `model-gateway`   | `POST /v1/chat/completions` with a team key and `x-importer`; 401, 402, a spend row per call | `route-calls-through-gateway` | Bedrock model access                    | Model Garden and Agent Gateway          | AI Gateway on API Management          | Spend must stop per importer, not only per key; our check proves it            |
| `tool-policy`     | Tool calls through one gateway; a denied call starts with `denied:`                          | `deny-the-planted-call`       | AgentCore Gateway and Policy (Cedar)    | Agent Gateway                           | Tools and MCP through AI Gateway      | The broker sign-off rule is ours: no product knows a licensed broker must sign |
| `agent-identity`  | `POST /token`, `POST /exchange`, an `act` claim; 401 for a wrong audience                    | `exchange-tokens-per-call`    | AgentCore Identity                      | Agent Identity                          | Entra Agent ID                        | Each token must be bound to one importer; we test that ourselves               |
| `tenancy`         | Row-level security forced on every table with an importer                                    | `isolate-importer-data`       | Do it yourself with Identity and Policy | Memory scoped per identity              | Entra and custom ids                  | The course brief found tenancy left to the builder on all three                |
| `memory`          | Recall filtered by importer before ranking                                                   | `scope-memory-per-importer`   | AgentCore Memory                        | Sessions and Memory Bank                | Foundry memory                        | Superseded rulings must never come back; we test that ourselves                |

| `durable-runs`    | A killed run resumes; a payment happens once                                                 | `resume-a-killed-run`         | Runtime sessions                        | Agent Runtime                           | Workflow agents                       | Idempotency keys on payments are still ours                                    |
| `traces-and-cost` | One trace per entry, `tenant` on every span, cost per importer                               | `split-cost-by-importer`      | AgentCore Observability                 | Cloud Trace                             | OpenTelemetry to Application Insights | Cost per released entry for each importer is a join we write                   |
| `release-gate`    | A gate command that exits 1 on a never-do metric or a low pass rate                          | `block-a-bad-release`         | AgentCore Evaluations                   | Gen AI Evaluation                       | Foundry evaluations                   | Zero tolerance for never-do metrics is our rule, not a product default         |
